# SPV Treasure Map - Frontend

Interactive map visualization of historical battles across France, UK, and Belgium built with **React** and **Mapbox GL JS**.

## 🚀 Features

- ✅ **Mapbox GL JS Integration** - High-performance vector maps
- 🗺️ **28 Battles Displayed** - Fetched from FastAPI backend
- 🎨 **Color-Coded Periods** - Visual distinction by war period
- 📍 **Interactive Markers** - Click for detailed battle information
- 📊 **Rich Popups** - Battle details including dates, outcomes, participants, casualties
- 🎛️ **Map Controls** - Navigation, scale, and fullscreen controls
- 📱 **Fully Responsive** - Optimized for mobile and desktop
- 🌍 **Legend** - Color legend for war periods

## 📦 Tech Stack

- **React 19** - UI framework
- **Vite** - Build tool and dev server
- **Mapbox GL JS** - Map rendering engine
- **react-map-gl 7.1.7** - React wrapper for Mapbox
- **Mapbox Token** - Pre-configured

## 🚀 Quick Start

### Prerequisites

1. **Backend API must be running** at `http://localhost:8000`
2. **Node.js** (v18 or higher)

### Installation & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at **http://localhost:5174/**
